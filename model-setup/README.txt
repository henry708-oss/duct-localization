All models are gonna need a model.config, model.sdf and model.stl

The .stl file is already generated by Zach’s carver program

We need a python program that will run the Carve function from mazecarver.py, take the output stl file
And then place it in a folder structured like this:

(<name> is a folder)

<model name>
	<meshes>
		model.stl
	model.config
	model.sdf

The model.config and model.sdf can pretty much just be copy pasted in to python in like a format string and then written but with templating to put the unique model name for each maze into <model name=“{model_name}”> in the .sdf;

the file path for the stl in <uri>model://{model_name}/meshes/model.stl</uri> in both uri tags in the .sdf;

The <name>{model_name}</name> in model.config
